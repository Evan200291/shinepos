Barcode Scanner

USB/Bluetooth barcode scanner for quick product lookup

  1. Plug the scanner into a USB port, or pair it over Bluetooth as a keyboard (HID).
  2. Click Test Scanner below and scan any barcode. The value should appear in the readout.
  3. Open the POS tab and scan products. They are added to the cart with a beep.
Disconnected

Enable the scanner, then click Test and scan any barcode. The captured value is shown here instead of being added to the cart.

Voucher / Receipt Printer

Thermal or standard printer for sales receipts

Direct printing sends raw ESC/POS commands straight to the printer — no popup, no print dialog, and it auto-cuts the paper. Works with most Epson-compatible thermal printers on Chrome or Edge desktop. The browser will ask you to pick the device once per session. If USB says "Access denied", Windows is using its own printer driver: switch Connection back to "Browser print dialog", or use Bluetooth/Serial for portable printers.
